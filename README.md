# LEK Gosi

Aplikacja do nauki do Lekarskiego Egzaminu Końcowego na bazie pytań CEM.
Statyczna strona (HTML + JS + JSON) – działa na GitHub Pages, Netlify lub dowolnym hostingu plików.

- `data/questions.json` – pytania z bazy CEM (3012)
- `data/keys.json` – klucz odpowiedzi z wyjaśnieniami (opracowany przez AI, nie oficjalny klucz CEM)
- postęp zapisuje się w przeglądarce (localStorage)
